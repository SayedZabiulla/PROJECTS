# 🚗 Car Rental System

A simple **Car Rental System** developed using **Core Java** that enables users to rent and return cars through a console-based interface. The project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** concepts such as classes, objects, encapsulation, and object relationships while managing cars, customers, and rental transactions.

---

## 📌 Features

- 🚘 View available cars
- 👤 Register customer details
- 🔑 Rent a car
- 🔄 Return a rented car
- 💰 Automatic rental price calculation
- 📋 Display rental information
- ✅ Input validation for user interactions
- 🖥️ Menu-driven console application

---

## 🛠️ Technologies Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Scanner Class
- Eclipse / IntelliJ IDEA / VS Code

## 📂 Project Structure

```text
com.sayedZabiulla.carRentalSystem
│
├── src
│   ├── Car.java
│   ├── CarRentalSystem.java
│   ├── Customer.java
│   ├── mainCar.java
│   ├── Rental.java
│   └── welcomeToShop.java
│
└── README.md
```

### File Description

| File | Description |
|------|-------------|
| **Car.java** | Defines the Car class with car details and availability status. |
| **Customer.java** | Represents customer information. |
| **Rental.java** | Stores rental transaction details between customer and car. |
| **CarRentalSystem.java** | Implements the business logic for renting and returning cars. |
| **mainCar.java** | Main entry point of the application. |
| **welcomeToShop.java** | Displays the welcome screen and menu interface. |

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or above
- Eclipse, IntelliJ IDEA, or VS Code

### Clone the Repository

```bash
git clone https://github.com/SayedZabiulla/PROJECTS.git
```

### Navigate to the Project

```bash
cd "PROJECTS/CORE JAVA PROJECTS/com.sayedZabiulla.carRentalSystem"
```

### Compile

```bash
javac src/*.java
```

### Run

```bash
java -cp src mainCar
```
