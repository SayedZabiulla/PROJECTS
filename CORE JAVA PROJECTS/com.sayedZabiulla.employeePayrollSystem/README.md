# Employee Payroll System

A simple **Core Java** console-based application that manages employee payroll details. This project demonstrates the fundamentals of Java programming, including Object-Oriented Programming (OOP), collections, and basic CRUD operations.

## 🚀 Features

- Add new employees
- View employee details
- Update employee information
- Remove employees
- Calculate employee salary/payroll
- Menu-driven console interface

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Classes & Objects
  - Encapsulation
  - Collections (if used)
  - Exception Handling

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/SayedZabiulla/PROJECTS.git
   ```

2. Navigate to the project directory.

3. Compile the Java files:
   ```bash
   javac *.java
   ```

4. Run the application:
   ```bash
   java Main
   ```
